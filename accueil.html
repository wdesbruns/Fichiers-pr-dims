Choisissez une calculette

Chaque module applique les règles des codes cités (CODETI, EN 13480, ASME, Eurocodes et annexes nationales françaises), avec les paragraphes de référence rappelés dans les résultats. Vous saisissez les données, le schéma et le verdict se mettent à jour instantanément.

1 · SAISIRLes champs bleus sont à renseigner. Les bases de données (tubes, matériaux, fluides) pré-remplissent les valeurs, qui restent modifiables.
2 · LIRE LE RÉSULTATChaque critère donne un taux = sollicitation / limite. Taux ≤ 100 % : ● OK. Taux > 100 % : ▲ NON CONFORME. Le critère ▲ dimensionnant est mis en évidence.
3 · JUSTIFIERLe bouton Imprimer / PDF produit une note de calcul avec les hypothèses, les formules et les références normatives.
Outils d'aide au calcul : les résultats doivent être vérifiés par un ingénieur qualifié. ·
