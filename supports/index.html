Données climatiques et sismiques

Critère ELS

Déplacement des points d'appui des tuyaux et de l'extrémité libre, sous combinaisons caractéristiques.

Règles de conception (bonnes pratiques, modifiables)

Platines semi-rigides : Sj = 10·E·I/L < 30·E·I/L (seuil de rigidité, NF EN 1993-1-8 §5.2.2.5) — hypothèse prudente qui augmente les déplacements ; la torsion de la barre reste bloquée. Pince des trous d'étrier : e2 ≥ 1,2·d0 (NF EN 1993-1-8 Tab. 3.3), jeu des trous d0 = d + 1 (≤ M14), + 2 (M16–M24), + 3 (≥ M27) (NF EN 1090-2). Diamètre d'étrier automatique indicatif (type DIN 3570) : DN ≤ 50 → M10 ; ≤ 100 → M12 ; ≤ 200 → M16 ; ≤ 350 → M20 ; au-delà M24 — à confirmer avec le catalogue fabricant.
